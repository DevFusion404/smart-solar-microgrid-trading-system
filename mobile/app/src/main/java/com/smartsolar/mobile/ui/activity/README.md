# Activities (`ui/activity`)

This package contains Android Activity components serving as entry points and main host screens.

## Planned Files
- **`MainActivity.kt`**: Main application container hosting fragments, bottom navigation, or drawer navigation.
- **`LoginActivity.kt`**: User authentication and session management screen.
- **`DashboardActivity.kt`**: User overview dashboard displaying microgrid status and quick booking actions.
- **`MapActivity.kt`**: Google Maps screen displaying solar station pins and real-time station availability.
