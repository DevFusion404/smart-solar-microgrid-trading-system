# Fragments (`ui/fragment`)

This package contains reusable UI fragments hosted within activities.

## Planned Files
- **`StationFragment.kt`**: Displays the list of available solar stations, search bar, and filter controls.
- **`SlotFragment.kt`**: Displays energy booking slots for a selected station with date picker.
- **`ReservationFragment.kt`**: Displays user reservation history and active energy trading bookings.
